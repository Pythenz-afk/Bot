Bot UI (minimal)

Quickstart

1. Install dependencies:

```bash
python3 -m pip install -r requirements.txt
```

2. Run the UI:

```bash
python3 app.py
```

3. Open http://localhost:5000 in your browser.

Or start everything with the included script:

```bash
./run.sh
# or
bash run.sh
```

Notes
- You can send messages using a Discord webhook URL, or via a bot token + channel ID.
- Be careful with bot tokens: do not share them publicly.
